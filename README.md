# PC Assembly & Disassembly (Lab Reflection)

In today's laboratory session, we conducted a practical hands-on exercise focused on the physical structure and internal component layout of a desktop PC. Once the main computer casing was opened, we began systematically disconnecting the internal power and data cables connecting the motherboard to various units. We then uninstalled key hardware components, including the main Power Supply Unit (PSU), the Random Access Memory (RAM), the mechanical hard disk drive, and the CPU cooler. Handling each module firsthand gave a much clearer view of how power distribution and component interconnections operate inside a standard tower PC setup. Then, we reinstalled every component back into its designated motherboard slot and drive bay. We concluded the lab by powering the unit back on to verify that all hardware components were functioning correctly.

Overall, this exercise provided a valuable practical foundation that connects theoretical computer architecture concepts with physical machine hardware. Experiencing how components like memory, storage, and CPU cooler physically link together makes it much easier to understand how software and operating systems interact. For future lab sessions,  I wish to have clear reference guides for internal cable routing beforehand which could help make the reassembly process even smoother for first-time hardware builders.
